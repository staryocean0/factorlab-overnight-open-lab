# Driver runtime text carrier (2015-2020)

Connector-readable development-only carrier for the causal SGX A50 and HKMA
USD/CNY driver coordinates used by Overnight/Open research. It publishes only
2015-2020 rows. 2021-2025 remain reusable BLACKBOX-governed and are not
materialized here.

This carrier is not new scientific evidence, not a fresh OOS sample, and not a
production dataset. Physical/textual accessibility does not grant evidence
authority. Each research identity still requires its own preregistration and
evidence boundary.
