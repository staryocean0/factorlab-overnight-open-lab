# 广义反转与均值回归研究交接

## 现在这个仓库研究什么

本仓已经从“次日高开/低开”单一专题，升级为**广义反转与均值回归方向发现项目**。

核心问题：

> 当前出现的异常运动，是完整父级状态里的低级别波动，还是父级状态本身已经发生改变？

“均值”不限定为均线，可以是父级趋势/波形、动态震荡区间、状态条件下的正常轨迹/分布、跨资产正常关系，或者路径效率/波动率等统计属性的正常状态。

## 第一批主线

当前同时浅层推进：

1. **R1 跨尺度回撤**：父级趋势完整时，突然的反向急跌/急涨是否只是低一级别波动？
2. **R2 震荡边界回归**：父级震荡时，冲出边界后是假突破回归还是进入真突破？
3. **R3 状态残差回归**：在不同市场状态下，实际路径相对“该状态正常路径/分布”的残差是否稳定回归？

旧的开盘高低开、Gap-Fill、跨指数 relative-gap-excess 归入 **R4 相对价值失衡**。这些结果保留，但已有专门研究线，本仓默认只把它当专题案例，不继续长期钻进去。

## 已经得到的方法论经验

旧 Overnight / Gap-Fill 工作最值得继承的不是某个具体模型，而是下面的经验：

- 单纯“偏离很大”不足以推出反转；
- 必须判断偏离发生时的背景状态；
- 同样的价格动作在不同父级状态下可以有完全不同的含义；
- 因此新的研究重点是**状态 + 尺度 + 偏离性质**，而不是继续堆一个专题的过滤条件。

旧实验的所有正式 receipt、audit、fresh/consumed 标签继续有效，不能因为项目升级就改写历史。
