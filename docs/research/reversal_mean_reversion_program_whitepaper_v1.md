# 广义反转与均值回归研究白皮书 v1

生效日期：2026-09-08

## 1. 研究对象

本项目研究的不是某一条均线附近的反弹，也不是某一个开盘高低开策略。

本项目研究的是一个更一般的问题：

> **当市场明显偏离当前“正常状态”时，这个偏离是暂时波动，还是正常状态本身已经改变？**

只有前者才是真正值得研究的均值回归机会。

因此，均值不必是一条线。它可以是：

- 某个价格水平或动态中心；
- 一个震荡区间；
- 一个趋势通道或父级波形；
- 当前市场状态下的正常价格轨迹；
- 一个统计分布的正常区域；
- 两个资产、两个指数或两个组合之间的正常关系；
- 路径效率、波动率、频段振幅等统计属性的正常状态。

## 2. 最核心的判别问题

举例：一个大级别上涨行情中，极短时间出现突然下跌。

不能因为“跌得多”就自动认为应该抄底。

真正的问题是：

1. 父级上涨状态是否仍然完整？
2. 这次下跌是否只是低一级别波动？
3. 还是它已经破坏了父级结构，成为同级别下跌的开始？

所以本项目最重要的研究目标是：

> **区分“完整父级状态中的低级别偏离”和“父级状态真正发生切换”。**

这也是趋势中的回撤、震荡中的假突破、统计残差回归等策略可以统一到一个框架里的原因。

## 3. 统一坐标系

以后任何反转假说都必须先回答四个问题。

### 3.1 尺度

市场运动至少分成：

- 低一级别；
- 当前研究级别；
- 父一级别。

同样一段快速下跌，在 5 分钟图上可能是主行情，在日线图上可能只是噪声。脱离尺度谈反转没有意义。

### 3.2 父级状态

至少先分成：

- 趋势；
- 震荡；
- 状态切换；
- 无法判断。

同样幅度的偏离，发生在强趋势、震荡中部和趋势衰竭附近，含义完全不同。

### 3.3 偏离对象

要说明到底是什么“偏离了正常”：

- 价格；
- 路径；
- 波形；
- 分布；
- 相对关系；
- 某种市场统计属性。

### 3.4 回归标准

要在看结果之前定义：

- 回到哪里算回归；
- 多久以内算回归；
- 什么情况算没有回归而是状态切换。

## 4. 第一批并行研究方向

本项目不再连续很多轮深挖一个具体策略。第一阶段同时保留三条主要路线，每条只做足以判断是否值得深挖的浅层研究。

### R1：趋势中的跨尺度回撤

场景：父级趋势明确，例如上涨；低一级别突然快速下跌。

研究问题：

> 能不能在反弹发生之前判断，这只是父级趋势中的低级别回撤，而不是父级趋势结束？

第一批可研究信息包括：

- 父级连续完整波形的漂移方向；
- 父级趋势斜率和稳定性；
- 当前反向运动相对父级波动的幅度；
- 当前反向运动速度；
- 路径效率；
- 是否破坏前一关键波形/结构；
- 是否仍处于父级合理波动范围。

第一阶段不追求最优抄底点，只检验：

1. 能否稳定定义父趋势；
2. 能否找到“父趋势未坏但子级出现急跌”的事件；
3. 这些事件是否比真正父级反转有更高的恢复概率。

### R2：震荡边界与假突破回归

场景：父级不是趋势，而是较稳定的来回震荡。

这里的“均值”更像动态区间，而不是一条固定均线。

研究问题：

> 当价格冲出震荡区间时，什么时候只是短暂过冲，什么时候是真突破？

第一批可研究信息包括：

- 区间持续时间和边界稳定性；
- 突破幅度相对区间宽度；
- 突破速度；
- 突破前后的路径效率；
- 波动率是否进入新台阶；
- 是否形成新的同级别波形；
- 区间外停留能力。

第一阶段只要求证明：

- 有可重复识别的父级震荡；
- 边界偏离之后确实存在“回区间”和“脱离区间”两种不同后果；
- 在结果发生之前能找到区分二者的信息。

### R3：市场状态条件下的残差回归

这一方向不先定义固定均线，而是先定义：

> 在当前市场状态下，正常情况下价格应该怎么走？

然后研究：

`实际路径 - 当前状态下的正常路径`

这个残差是否会回归。

“正常状态”可以来自简单模型，也可以以后来自多状态/Koopman/状态空间等框架，但第一阶段禁止直接上复杂模型。

先用低容量定义证明三个问题：

1. 市场确实存在多个具有不同动力特征的状态；
2. 同样的价格偏离在不同状态下含义不同；
3. 在状态条件化以后，残差的回归性是否比无条件偏离更稳定。

只有这三个问题成立，才值得升级更复杂的动力模型。

## 5. 第二层方向

### R4：相对价值 / 跨资产失衡

两个指数、行业、个股组合、期现等之间存在正常关系。关系暂时偏离时可能产生回归。

现有开盘高低开、Gap-Fill V2/V2.1、CSI300/CSI500 相对跳空等工作属于这一大类。

这些研究本身没有失效，但已经有专门研究线，因此在本项目里只作为：

- 已有案例；
- 方法论参考；
- 未来不同方向的对照。

不再占用主研究预算。

### R5：统计状态的极端回归

价格以外的市场属性也可能偏离正常水平，例如：

- 路径效率；
- 波动率；
- 指定频段振幅；
- 波动聚集程度；
- 上下行不对称；
- 波形持续时间。

这类变量可能既用于判断父级状态，也可能自身构成均值回归机会。第一阶段先作为候选信息源，不立刻建立独立复杂策略。

## 6. 本项目的研究方法

### 6.1 先广后深

本仓首先负责“发现方向”。

默认同时研究 2–3 条路线。每条路线先投入相近的小研究预算。

一个方向的浅层验证应该尽量只回答：

- 现象有没有；
- 能不能事前识别；
- 是否跨时期或跨尺度存在；
- 数据和定义是否可靠；
- 是否值得建立专门子项目。

在其他主要方向还没有获得同等浅层检查之前，不允许连续很多轮优化同一个方向。

### 6.2 先研究机制，再研究收益

第一阶段不能因为某组参数回测收益最好就选它。

优先看：

- 条件概率差异；
- 后续路径分布；
- 回归/继续两类事件的可分性；
- 跨年份稳定性；
- 不同尺度是否重复出现。

交易工具、手续费、滑点和账户问题只有在机制真正站住以后才进入。

### 6.3 失败不救

如果一条方向在提前冻结的浅层条件下没有稳定现象，应关闭或降级。

不能在看到失败后不断增加：

- 新阈值；
- 新过滤条件；
- 新市场状态；
- 新模型；
- 新样本区间；

直到它看起来有效。

### 6.4 专题成熟后分仓

本项目最好最终产生的是几条清楚的研究分支，而不是一个越来越大的万能模型。

一条路线达到以下条件时，可以毕业到专门仓库/研究身份：

- 机制明确；
- 事前可观测；
- 样本数量足够；
- 至少跨多个独立时期或尺度出现；
- 简单模型就能看到差异；
- 有明确的后续审计数据。

毕业以后再采用严格的候选预算、sealed audit、fresh challenge 和执行层研究。

## 7. 与旧 Overnight / Gap-Fill 研究的关系

旧研究保存全部事实和证据，不重写历史。

包括：

- 次日高低开预测；
- high-open recall；
- offshore China price discovery；
- Gap-Fill V2；
- V2.1 relative-gap-excess；
- 已冻结的 2026Q4 fresh challenge；
- 数据源 admission 和各种 sealed boundary。

这些文件仍然对它们自己的实验有权威性。

但是从 2026-09-08 起：

> **它们不再拥有“本仓下一步应该做什么”的仓库级权威。**

任何未来助手如果因为读取某个旧 state 文件看到 `next_action = verify receipt / run V21 DEV`，不得把它自动当成本项目主线。

只有用户明确要求恢复该专题，或者广义框架把 R4 重新选为优先方向，才继续深入。

## 8. 当前进度

过去的 Overnight / Gap-Fill 专题已经给本项目留下一个有价值的方法论经验：

> 偏离本身不够，必须先判断偏离的背景和性质。

但广义项目本身现在处于早期：

- 统一定义框架已确定；
- R1/R2/R3 已被确定为第一批并行方向；
- 尚未为三条路线正式冻结统一测量合同；
- 尚未进行可比的浅层实证筛选。

因此真正的下一阶段是：

> **建立统一的尺度/状态/偏离/回归定义，然后分别给 R1、R2、R3 做一轮低成本、可否证的浅层研究。**

生产权限始终为 `false`。
