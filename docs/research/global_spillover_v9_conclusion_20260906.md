# v9 结论：保留小幅增量材料，不替换 V6

本轮完成了已在 `9554809c` 冻结、此前尚未执行的单候选检验：在 V6A
基础上只增加普通交易日 A50 收益的 `x|x|` 项。数学实现、因果输入时间、
冻结父模型复现及训练范围内的金融方向约束均通过，但年度、季度和假期
稳定性条件未通过。**V9 不升级；V6A 继续作为等待未见确认的研究候选。**

这是 2019–2020 已使用样本上的重复研究，不能称为新样本外验证。
2015–2018 训练；2021–2025 未读取。没有搜索其他幂次、阈值、alpha，
没有删事件重拟合，也没有改写 V6 的独立未见确认合同。

## 为什么没有升级

预注册要求同时通过全部条件。四项失败：

| 条件 | 实际结果 | 裁决 |
|---|---|---|
| 2019、2020 各年 SSE 均不得变差 | 2019 增加 0.000118049；2020 减少 0.000283970 | 失败 |
| 至少 5/8 季度 SSE 不变差 | 4/8 | 失败 |
| 季度 SSE 改善中位数为正 | -0.000001770 | 失败 |
| 假期子样本 SSE 不变差 | 11 天合计增加 0.000003085 | 失败 |

| 季度 | V6 SSE − V9 SSE |
|---|---:|
| 2019Q1 | -0.000020045 |
| 2019Q2 | -0.000119743 |
| 2019Q3 | -0.000043468 |
| 2019Q4 | +0.000065206 |
| 2020Q1 | +0.000115305 |
| 2020Q2 | +0.000200141 |
| 2020Q3 | -0.000047981 |
| 2020Q4 | +0.000016505 |

金融方向约束通过：879 个普通训练观测的 A50 边际斜率最小值
0.263679、中位数 0.327547、最大值 1.927935，没有非正值。
新项的标准化系数为 +0.00241315，线性 A50 系数从 +0.00377181
降至 +0.00177096。训练拟合允许大冲击有更强传导，未产生方向反转。
这只说明该函数的金融方向合理，不能补偿稳定性条件的失败。

假期的新项严格为零，但重新拟合整组 Ridge 系数仍会改变假期预测。
因此“假期特征保持原定义”不等于“假期预测保持不变”；相应保护条件
已经如实判为失败。

## 固定预测归因

总体 269 天误差改善、192 天变差；普通日为 261/450 天改善。
但正负贡献抵消后，净增量非常脆弱：

| 固定预测诊断，不重拟合 | 剩余 SSE 改善 |
|---|---:|
| 全部观测 | +0.000165920 |
| 去掉最大正贡献 1 天 | -0.000160751 |
| 去掉最大正贡献 5 天 | -0.000467957 |
| 去掉最大正贡献 10 天 | -0.000624398 |

最大贡献来自 2020-02-04，单日贡献约 +0.000326671，超过总体净增量。
该日实际缺口 -5.3262%，V6 预测约 +0.2414%，V9 约 -0.0601%，
两者仍显著低估实际下跌幅度。仅预测略向正确方向移动，就能在平方误差
指标上形成很大的贡献；不能据此声称模型已经解释了该极端事件。

普通日 `x|x|` 与线性 A50 的相关系数为 0.824925，与目标的相关系数
0.590520，但与 V6 固定残差仅 0.037182。前后错一行的目标相关分别
约 0.008097、-0.069138。这里的一行指可用普通日样本顺序，未宣称
相邻交易日或统计显著性。

负 A50 冲击组 177 天的 SSE 净改善为 +0.000195563；正冲击组
270 天为 -0.000032799；零冲击 3 天为 +0.000006241。
这些是预先要求的非选择性诊断，未据此增加方向分组模型。
整体证据支持“这一个变换有小幅但不稳定的边际增量”，不支持
“所有非线性方法都无效”，也不支持继续在这组已用样本上逐个换函数。
