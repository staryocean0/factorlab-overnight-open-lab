状态：普通日主桶冻结为 |涨跌幅|≤1% 且振幅≤2%；再按周线上涨 / 普通 / 下跌拆成三桶

## 1. 为什么改阈值

V1.1 用 MAD×2 切尾，留下约 89%，上下界大约 -2.22% 到 +2.52%。这对「普通日内」仍然太宽。真正的普通日涨跌到不了 1%；涨跌幅为 0 但早盘暴高开再走回去的日子，振幅会暴露外力。

经验上中证1000 日振幅中位数 / |涨跌幅|中位数 ≈ **1.84**，周线 ≈ **1.86**。振幅取涨跌幅两倍，不是拍脑袋。

冻结：

| 级别 | 涨跌幅上限 | 振幅上限 | 振幅定义 |
|---|---:|---:|---|
| 日线 | **1%** | **2%** | (high-low)/昨收 |
| 周线 | **2.5%** | **5%** | (周高-周低)/上周收 |

周线 2.5% 是日线 1% 的同位置类比（约 0.8 个稳健 σ，也接近 1%×√5）。禁止再网格搜索。

## 2. 四个桶

1. **daily_main**：|close-to-close|≤1% 且振幅≤2%。约一半交易日。
2. **main ∩ weekly_up**：主桶日，所在周净涨 >2.5%。
3. **main ∩ weekly_ordinary**：主桶日，所在周 |净涨跌|≤2.5% 且周振幅≤5%。
4. **main ∩ weekly_down**：主桶日，所在周净跌 < -2.5%。

周振幅超限但净涨跌仍在 2.5% 内的日子记 `wide` 余项，不当第五个科学桶。周线是周五收周。含当周信息的分桶是机制材料，不是盘中闸。

## 3. 中证1000 四个桶的时段形状

主桶（1230 日）：

| 时段 | 均值 | std | 可用 |
|---|---:|---:|---|
| overnight | **-6.3 bp** | 29 | 是 |
| first30 / 09:31–10:30 | **+6.9 / +7.8 bp** | 38 / 43 | 是 |
| 10:31–11:30 | +2.1 bp | 37 | 是 |
| 13:01–14:00 | **-3.1 bp** | 34 | 是 |
| 14:01–15:00 | +2.8 bp | 37 | 是 |
| 下午整体 | ≈0 | 47 | 否 |

标准差比全样本小一半以上。普通日里，早盘仍涨，隔夜仍低开，早午后微跌、尾盘微抬，对冲成下午接近 0。

主桶再按周线拆开：

| 子桶 | n | overnight | first30 | morning | afternoon |
|---|---:|---:|---:|---:|---:|
| 周线上涨 | 225 | -1.8，不可用 | **+15.0** | **+17.8** | **+6.7** |
| 周线普通 | 802 | **-7.5** | **+5.2** | **+9.7** | -1.1，不可用 |
| 周线下跌 | 155 | **-7.1** | +1.0，不可用 | ≈0 | **-6.8** |

这就是「日线看起来普通、其实从属于周线趋势中继」：上涨周里的安静日仍在走多，下跌周里的安静日下午仍在走空。真正接近无外力的时段形状在 **周线普通 ∩ 日线主桶**。

## 4. 周线普通桶：净涨跌≈0，四段两波

802 个「日线主桶 ∩ 周线普通」日子的 close-to-close 均值 **+1.48 bp**（se 1.85，t=0.80，95% 区间 [-2.2, +5.1]），净漂移已经在 0 附近。把当天净涨跌回归掉以后，截距仍是同一套形状，不是再混进的长期牛市漂移。

平均路径是四段、两波来回，不是「上午一波、下午一波」：

| 顺序 | 时段 | 原始均值 | r=0 截距 |
|---|---|---:|---:|
| 1 | 上午 09:31–11:30 | +9.7 bp | +9.1 bp |
| 2 | 13:00–14:00 | -3.8 bp | -4.0 bp |
| 3 | 14:00–15:00 | +2.7 bp | +2.2 bp |
| 4 | 隔夜 | -7.5 bp | -7.7 bp |

隔夜低开和上午上涨跨年更稳。13:00–14:00 变负是 **2018 年以后**才进这只最干净的桶；2015–2016 同一桶里午后第一小时仍为正，且在 r=0 时截距仍为正。前 20 日热度对午后系数约为 0。因此这是时段时钟换挡，不是漂移多寡。下午整体接近 0，是早午后微跌和尾盘微抬对冲出来的。

这是普通日平均路径，不是每天都走完的交易时钟，也不是 Layer 1 新时钟。

## 5. 权威


`production_authority=false`。不改 `@2.3` pointer。1%/2% 和 2.5%/5% 不是以后每年都重估的日历规则。
